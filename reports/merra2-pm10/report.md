## 摘要

为构建研究区域近地面PM₁₀的连续时空数据，本阶段采用NASA发布的MERRA-2三维气溶胶再分析产品M2I3NVAER 5.12.4，选取最接近地面的第72模式层，获取空气密度及硫酸盐、黑碳、有机碳、沙尘和海盐相关变量。依据当前采用的文献组分方案，在原始网格上逐时次估算PM₁₀，保留3小时时间分辨率，并按区域、按年份保存为NetCDF4。

国内范围为宁夏、新疆、甘肃和内蒙古，国外扩展范围为蒙古国、哈萨克斯坦、吉尔吉斯斯坦、塔吉克斯坦、阿富汗、巴基斯坦和印度。本阶段重点获取2015年至最新实际可用日期的数据，保留原始日文件和任务记录，为后续点位提取、方法复核及观测比较提供可追溯的数据基础。

现有运行记录表明，蒙古国2024年已完成366个日文件、2928个时次的PM₁₀计算和年度写出，验证了完整年度处理流程。多区域、多年份任务仍在推进，实际完成范围需逐年盘点。城市代表点的来源、地面观测资料和时空配对规则仍需核实，因此本报告分别说明已实施方法、已完成验证和后续评价方案，不提前给出估算精度结论。

关键词：MERRA-2；M2I3NVAER；近地面PM₁₀；区域子集；NetCDF4；时空匹配

## 1  研究目标与总体技术路线

研究区域跨越不同地形和观测条件，单一地面站网难以直接提供统一、长期、完整的网格资料。本阶段拟利用MERRA-2的时空连续性，建立可重复计算的近地面PM₁₀数据集，并在后续通过地面观测检验其变化特征及偏差。扩展至周边七国的目的，是为后续区域联系和跨区域过程研究储备一致的数据基础；具体输送关系和沙尘来源仍需进一步分析。

技术路线分为五个环节：区域子集请求、原始日文件下载、组分法计算PM₁₀、年度网格结果保存，以及目标位置匹配与观测比较。前四个环节形成可复用的数据基础，最后一个环节用于评价研究位置上的表现。

## 2  数据来源、产品特征与研究范围

### 2.1 MERRA-2及所选产品

MERRA-2是NASA全球建模与同化办公室（GMAO）开发的再分析资料，通过数值模式和观测约束形成长期、连续的大气与气溶胶数据。本研究从NASA GES DISC获取M2I3NVAER产品。气溶胶再分析与地面PM₁₀直接测量的物理含义和空间代表尺度不同，需要通过独立地面资料评价[1—3]。

表1  所用产品及关键参数

| 项目 | 本研究采用的信息 |
| --- | --- |
| 产品简称与版本 | M2I3NVAER，5.12.4；文件产品标识inst3_3d_aer_Nv |
| 产品性质 | 三维、3小时、瞬时、模式层气溶胶质量混合比产品 |
| 数据来源 | NASA GES DISC；产品DOI：10.5067/LTVB4GPCOTK2 |
| 产品时间覆盖 | 自1980年起；实际最新日期随数据发布更新 |
| 本阶段重点时期 | 2015年至最新实际可用日期，未将当前年份视为完整全年 |
| 水平网格间距 | 经度0.625°、纬度0.5°；对应物理距离随纬度变化 |
| 时间坐标 | 每日UTC 00、03、06、09、12、15、18、21时 |
| 垂直层次 | 共72个模式层；选择最接近地面的第72层 |
| 文件格式 | NetCDF4，原始日文件扩展名通常为.nc4 |

产品元数据明确规定lev=1为顶部模式层，lev=72为底部模式层[1]。第72层不是固定离地高度，不能等同于地面仪器采样高度或固定的2米层。产品为3小时瞬时值，也不能直接写为3小时平均浓度。

## 3  数据获取、预处理与完整性控制

### 3.1 NASA区域子集获取

通过Python调用NASA Harmony服务，提交研究区域多边形、起止时间、所需变量和lev=72条件，仅获取PM₁₀估算所需的数据。任务按区域、按年份组织，便于单独恢复和补齐；年代目录仅用于文件管理，不表示将十年数据合成为一个服务端任务。

服务端处理完成后，获取逐日结果链接并保存为年度TXT清单，同时记录任务编号、请求范围、状态及链接有效期。随后由下载程序读取清单，保存原始NetCDF日文件。因此，链接获取与实体数据下载是两个环节。任务完成状态和链接日期覆盖均满足要求后，才能将清单用于完整年度处理。

### 3.2 日文件下载和区域预处理

下载程序先完成首个缺失文件的认证，再并发下载后续文件。每次运行输入一次账号和密码，在本次国家和年份任务中复用；凭据不写入研究数据。已有文件经过校验后复用，完整年度结果通过检查后跳过。并发用于减少网络等待，实际速度受服务端负载、网络和磁盘共同影响。

本地读取时检查时间、变量、层次、单位及经纬度。计算沿用原始网格，不在本阶段人为加密或重新插值。依据区域多边形筛选网格中心，构建区域掩膜，区域外位置设置为缺失。对区域边缘目标，后续匹配前单独检查是否需要补充网格。

### 3.3 时间覆盖与文件质量控制

表3  下载与计算的质量控制内容

| 检查对象 | 检查内容 | 处理原则 |
| --- | --- | --- |
| 任务与链接 | 任务状态、编号、有效期及日文件日期 | 不将部分成功结果标记为完整年度 |
| 年度日文件 | 起止日期连续、无缺失或重复 | 历史完整年对应365或366个日文件 |
| 日内时间 | UTC每3小时一个时次、顺序一致 | 完整日应有8个时次；当前年按实际截止检查 |
| 变量与层次 | 14个必要变量、第72层、单位和维度 | 缺变量、层次或单位异常时暂停计算并核查 |
| 空间网格 | 日文件经纬度一致、区域有效网格覆盖 | 不以文件能打开代替空间一致性检查 |
| 结果数值 | 缺失、非有限值、空气密度及异常浓度 | 保留缺失含义；不静默填零或裁剪异常 |
| 年度输出 | 时次总数、公式、单位及完整写入 | 检查通过后作为完成结果保存 |

例如，平年完整年度应有365×8=2920个时次，闰年应有366×8=2928个时次。当前年份仅处理数据实际覆盖的日期，不因文件以年份命名就视为全年完整。

### 3.4 中断、异常及可追溯性

任务处理进度达到100%只表示执行结束，仍需检查最终状态和日期覆盖。NASA服务端超时或部分处理失败时，保留任务记录和已成功文件，针对缺失部分补齐；不通过放宽完整性条件掩盖缺测。临时结果链接过期后，如本地文件完整可继续使用，缺失文件则需刷新链接。

程序保留区域边界校验和、请求配置、任务编号、原始文件校验信息和输出报告，使中断恢复与结果复查有据可依。具体接口异常和软件修复过程另作技术记录，不作为PM₁₀估算结果。

## 4  近地面PM₁₀估算方法

### 4.1 输入变量及单位

从第72模式层提取空气密度及气溶胶组分质量混合比，共14个变量。所有参与计算的变量必须对应相同时间和空间位置，并核对单位、维度及缺失值定义。

表4  PM₁₀计算的输入变量

| 变量名称 | 物理含义 | 单位 |
| --- | --- | --- |
| AIRDENS | 空气密度 | kg m⁻³ |
| SO4 | 硫酸盐气溶胶质量混合比 | kg kg⁻¹ |
| BCPHOBIC、BCPHILIC | 疏水性、亲水性黑碳质量混合比 | kg kg⁻¹ |
| OCPHOBIC、OCPHILIC | 疏水性、亲水性有机碳质量混合比 | kg kg⁻¹ |
| DU001—DU004 | 第1至第4粒径档沙尘质量混合比 | kg kg⁻¹ |
| SS001—SS004 | 第1至第4粒径档海盐质量混合比 | kg kg⁻¹ |

### 4.2 组分估算公式

依据现有参考材料采用的组分方法，将相关气溶胶质量混合比加权求和，再乘以空气密度，得到近地面PM₁₀质量浓度。以S表示加权质量混合比，公式分行列示如下：

```text
S = 1.375×SO4 + BCPHOBIC + BCPHILIC
```

```text
+ OCPHOBIC + OCPHILIC + DU001 + DU002 + DU003
```

```text
+ 0.74×DU004 + SS001 + SS002 + SS003 + SS004
```

```text
PM₁₀ = S × AIRDENS × 10⁹                         （1）
```

各质量混合比单位为kg kg⁻¹，S与AIRDENS相乘后单位为kg m⁻³，再乘以10⁹转换为μg m⁻³。当前方案中硫酸盐系数为1.375，DU004系数为0.74，其余列出的组分系数为1。代码按同一公式实现，不额外加入未明确采用的组分或系数。

公式目前依据所提供学位论文第10页实施。其完整书目信息、系数原始出处及适用性仍待核实，正式定稿前补齐。因此本文称其为“当前采用的文献组分方案”，不将其表述为NASA直接提供的PM₁₀变量或官方统一计算公式。

### 4.3 缺失值与异常处理

必要输入缺失时，相应网格和时次的结果保留为缺失，不把缺失组分视为零。区域外掩膜、区域内缺测及异常数值分别记录。对非正空气密度等不符合物理意义的输入暂停计算并核查，不在后台静默替换；对负PM₁₀等结果核查原因，不直接裁剪为零。

式（1）同时包含沙尘、海盐和其他气溶胶组分，所得为总PM₁₀估算浓度。若后续分析沙尘贡献，需要另行提取和定义沙尘组分指标；若识别沙尘事件，还需结合观测和事件判据。总PM₁₀高值本身不能直接证明发生沙尘过程。

## 5  结果存储、空间匹配与时间统一

### 5.1 逐时次计算和年度保存

计算按日文件、按时次顺序读取所需变量，完成单个时次后写入年度文件，避免将全部年份和组分一次载入内存。中间计算采用float64，最终PM₁₀以float32存储并使用NetCDF4压缩。压缩对已存储数据是无损的，但float64转float32存在舍入，两者应区分。

原始日文件与年度网格PM₁₀同时保留。NetCDF4能够组织时间、纬度和经度维度，并保存单位、缺失值、掩膜和公式说明；相较于全网格CSV展开，更适合多年网格资料的管理及按需读取。后续仅对目标点提取结果输出CSV或Parquet，减少表格规模。

表5  数据分层保存及用途

| 数据层次 | 保存方式 | 主要用途 |
| --- | --- | --- |
| 任务和链接 | 按地区／年代／年份保存JSON和TXT | 任务恢复、日期检查及下载入口 |
| 原始变量 | 按地区／年份保存逐日.nc4 | 核查组分、调整公式和复算 |
| 网格PM₁₀ | 按地区、每年一个NetCDF4 | 保留完整区域网格和原始3小时时次 |
| 目标位置序列 | 按国家或省份／城市或站点组织 | 观测配对、统计分析和成果输出 |

### 5.2 最近邻空间匹配

后续依据目标点经纬度，以球面距离选择最近的原始网格中心，并提取相应时间序列。结果保留输入坐标、匹配网格坐标及距离。该方法已进行流程测试，最终应用仍需检查点位来源和区域覆盖。多个点位可能匹配同一网格，反映数据分辨率限制。

现有city四省.xlsx包含45个城市或地级行政区代表点，其中内蒙古12个、甘肃14个、宁夏5个、新疆14个。现有字段不足以认定为空气质量监测站，本文暂称“给定代表点”。正式站点比较需核实名称、编号、坐标来源及参考系统，不能由此前气温匹配用途推定其为空气质量站。

边界附近的最近网格可能位于区域掩膜之外，应检查必要网格是否被保留，必要时补充局部数据。不得以距离更远的区域内网格自动替代，而不记录这一改变。

### 5.3 时间统一和输出字段

网格结果保留UTC时间。国内展示可增加北京时间UTC+8；年末UTC时次转换后落入次年属于正常时区转换。跨国日均统计需要明确采用UTC日还是所在地日，不能统一套用北京时间日界。

产品瞬时值、观测小时均值和观测日均值的时间含义不同，应根据观测时间戳制定配对窗口及有效比例要求。由每日8个瞬时值形成的均值应明确为“8时次均值”，不未经评估就等同于24小时观测日均值。

建议输出字段为国家／省份、城市／站点及编号、目标经纬度、匹配网格经纬度、距离、UTC时间、必要的当地时间、PM₁₀和质量标识。城市多年序列如超过表格软件显示限制，可按年拆分或采用Parquet；软件行数限制不等于数据无法存储。

## 6  地面观测比较方案

### 6.1 比较对象与数据准备

若观测为单站资料，使用该站坐标提取；若为城市平均浓度，需记录参与站点及平均方法。城市代表点对应网格与城市平均值的比较可以作为探索性分析，但需说明空间代表性差异。国外资料同样应核查污染物类型，避免将气象站或仅提供PM₂.₅的站点作为PM₁₀观测源。

配对前统一浓度单位和时间基准，核查观测质量标识、缺测、站点迁移及温压换算定义。缺失值不填零；本阶段不预设对PM₁₀缺测进行线性插值，以免改变污染高值过程。只有满足统一质量规则的配对进入评价，并报告各位置的有效样本数及覆盖时段。

### 6.2 指标与图表

令Mᵢ为第i组配对中的MERRA-2估算值，Oᵢ为观测值，N为有效配对数。拟采用平均偏差（MB）、平均绝对误差（MAE）、均方根误差（RMSE）和相关系数r，从系统偏差、误差幅度及变化一致性评价。

```text
MB = (1/N) Σᵢ₌₁ᴺ (Mᵢ − Oᵢ)                         （2）
```

```text
MAE = (1/N) Σᵢ₌₁ᴺ |Mᵢ − Oᵢ|                       （3）
```

```text
RMSE = √[(1/N) Σᵢ₌₁ᴺ (Mᵢ − Oᵢ)²]                 （4）
```

MB为正表示整体偏高，负值表示整体偏低；MAE和RMSE均以μg m⁻³表示，后者对大误差更敏感。相关系数用于评价变化一致性，不代替浓度偏差评价。样本过少或某一序列无变化时不强行计算r。

表6  拟形成的比较成果

| 成果 | 主要内容 | 对应问题 |
| --- | --- | --- |
| 时间序列图 | 同位置、同尺度的估算与观测变化 | 季节变化和污染过程是否一致 |
| 散点图 | 估算值与观测值、1∶1参考线 | 有无整体偏差及高值偏离 |
| 指标汇总表 | N、有效时段、MB、MAE、RMSE、r | 不同位置的误差和样本覆盖差异 |
| 分组分析 | 季节或明确判据下的高浓度过程 | 方法适用条件与过程差异 |

### 6.3 结果解释原则

差异可能涉及网格尺度、复杂地形、局地排放、近地面层高度、时间抽样和组分参数化等。分析应结合具体证据，避免把所有差异归于单一原因。目前尚无完整、经核查的地面PM₁₀配对结果，本节为评价方案，不能提前写入“准确性较高”等结果性结论。
