## 1  数据介绍与选择依据

本研究以MERRA-2气溶胶再分析资料为基础，构建研究区域近地面PM₁₀数据，为后续城市或监测站提取及地面观测比较提供统一的数据来源。所选资料需要同时具备可用于颗粒物估算的组分变量、近地面垂直信息，以及支持多年和跨区域分析的时空覆盖。基于上述要求，本阶段采用M2I3NVAER 5.12.4产品，获取所需区域和第72模式层数据，并保留原始水平网格与3小时时次。

### 1.1 数据来源与基本性质

MERRA-2（Modern-Era Retrospective Analysis for Research and Applications, Version 2）是美国国家航空航天局（NASA）全球建模与同化办公室（GMAO）开发的第二代现代时期研究与应用回顾分析资料，由Goddard Earth Observing System（GEOS）模式及资料同化系统生成，并通过NASA Goddard Earth Sciences Data and Information Services Center（GES DISC）提供访问与分发[1—3]。

MERRA-2通过数值模式与观测约束形成连续的大气和气溶胶场，其长期、统一的覆盖有利于在不同区域采用一致的数据和处理方案。该资料提供硫酸盐、黑碳、有机碳、沙尘及海盐等组分信息，使本研究能够在统一网格上从组分质量混合比出发估算近地面颗粒物浓度。与此同时，再分析值具有模式网格的空间代表尺度，不能直接视为单个地面监测站的测量结果[2—3]。

### 1.2 所用产品及其时空特征

本研究采用的具体产品为M2I3NVAER 5.12.4，对应文件标识inst3_3d_aer_Nv，属于三维、3小时、瞬时、模式层气溶胶质量混合比产品。选用该产品的直接原因，是其可在同一时空坐标下提供所需气溶胶组分和空气密度，并允许提取底部模式层，为后续近地面PM₁₀估算提供相互对应的输入。产品关键信息见表1，水平网格间距按“经度×纬度”列示[1]。

### 1.3 本研究选取的变量与范围

本研究从第72模式层选取14个变量，其中13个为所需气溶胶组分质量混合比，另1个为空气密度AIRDENS。变量集合与后续采用的组分估算方案对应，并非该产品的全部变量。质量混合比的单位为kg kg⁻¹，表示单位质量空气中的相应组分质量；只有与空气密度等信息结合并完成单位换算后，才能得到单位体积空气中的颗粒物质量浓度。表2列出实际请求的变量。其组分权重和具体换算公式见第2.4节。

**表2  本研究获取的14个变量**

| 变量名称 | 物理含义 | 单位 |
| --- | --- | --- |
| AIRDENS | 空气密度 | kg m⁻³ |
| SO4 | 硫酸盐气溶胶质量混合比 | kg kg⁻¹ |
| BCPHOBIC、BCPHILIC | 疏水性、亲水性黑碳质量混合比 | kg kg⁻¹ |
| OCPHOBIC、OCPHILIC | 疏水性、亲水性有机碳质量混合比 | kg kg⁻¹ |
| DU001—DU004 | 第1至第4粒径档沙尘质量混合比 | kg kg⁻¹ |
| SS001—SS004 | 第1至第4粒径档海盐质量混合比 | kg kg⁻¹ |

空间范围分为国内四省区和国外七国。国内为宁夏、新疆、甘肃和内蒙古；国外为蒙古国、哈萨克斯坦、吉尔吉斯斯坦、塔吉克斯坦、阿富汗、巴基斯坦和印度。国内区域采用geoBoundaries的CHN ADM1省级边界，国外采用Natural Earth v5.1.2的1:50m国家级边界，下载和计算沿用对应区域多边形[4—5]。具体范围以实际边界版本为准，边界文件和校验信息随任务保留。

本阶段重点获取2015年至最新实际可用日期的数据，以衔接后续能够获得的地面观测资料；最终配对年段仍由观测有效覆盖决定。产品自1980年起的覆盖范围与本阶段重点下载范围分别记录，实际完成范围依据各地区、各年份的文件及运行记录确定。

## 2  数据获取、PM₁₀计算与保存方法

本研究采用“区域子集获取—原始日文件下载与校验—逐时次PM₁₀计算—年度结果组织”的处理路线。前两个环节获得并保存原始组分，后两个环节生成便于后续位置提取的派生浓度场。原始数据与派生结果分别保留，使下载、复算和城市／站点匹配能够独立检查和调整。

![原始数据获取与年度PM₁₀构建流程](assets/data_processing_flow.png)

### 2.1 区域子集请求与逐日链接获取

数据通过NASA GES DISC获取，使用Earthdata Login账户认证，并按服务要求完成授权。Python程序调用Harmony子集服务，将研究多边形、年份范围、14个变量和lev=72一并作为请求条件。历史完整年请求1月1日00时至12月31日21时（UTC）；当前年份截至目录最新实际可用的完整日时次。子集方式在传输前限制区域和层次，减少全球三维资料中本研究不使用的部分。

请求按处理区域和年份组织。NASA完成任务后提供逐日NetCDF结果链接，程序读取全部结果页，提取实体文件地址，经日期检查后写入年度TXT清单；同时在JSON中保存请求条件、任务编号、状态和有效期。TXT是下载地址集合，JSON是任务追溯记录，二者均不等于原始数值已经下载到本地。年代文件夹仅用于管理年度清单，不表示将十年资料合为一个文件或一个作业。

完整性以实际请求范围为准：服务端任务成功结束后，仍需检查每日链接是否连续、有无重复、是否对应同一年及同一任务。部分成功的结果不能直接作为完整年度清单。对已成功任务优先恢复和复用；仅在结果过期、配置需要更新或确需重新处理时刷新相应任务。

### 2.2 临时结果有效期与下载安排

Harmony生成的是临时子集结果。任务返回的data_expiration表示该次结果在NASA端的保存截止时间，程序将其写入任务记录，并在生成清单后以UTC打印。到期约束针对这次子集结果的后续访问，不是MERRA-2原始资料的观测截止时间，也不是本地已下载文件的保存期限。不同任务应读取各自的有效期，不统一假定固定保存天数。

**表3  三类时间信息及其用途**

| 时间信息 | 含义 | 本项目记录 |
| --- | --- | --- |
| 资料覆盖时间 | 本次请求所对应的大气状态时段 | start、stop |
| 清单写出时间 | 下载链接何时整理写入本地 | links_written_utc |
| 临时结果到期时间 | NASA端本次子集结果的保存截止 | data_expiration |

以巴基斯坦2026年任务日志为例，打印的结果到期时间为2026-11-20 05:34:09.037 UTC，对应北京时间2026-11-20 13:34:09.037。该时间只用于安排这一任务结果的下载，不能套用到其他国家或年份，也不能据此推定2026年数据已经覆盖全年。具体截止仍以对应任务记录和NASA实时状态为准。

因此，应在获取链接后及时完成实体文件下载。到期前尚未下载的部分应优先补齐；已过期且本地文件缺失时，查询或刷新相应任务结果后再下载。对已完整保存且校验通过的原始文件和PM₁₀结果，可继续离线使用，无需因链接到期而全部重下。任务记录和原清单仍保留用于追溯。

### 2.3 原始日文件下载与校验

下载程序读取本地年度清单，先检查是否已有合格缓存，仅获取缺失日文件。首次缺失文件串行完成认证，随后并发下载；账号密码在每次运行中输入一次并复用。并发主要减少网络等待，不能据此假定计算过程也进行了多线程或GPU加速。实际速度由网络、服务端和本地读写共同决定。

校验分为文件完整性和内容一致性：前者结合传输长度、文件校验信息及NetCDF可读性判断文件是否完整，后者检查日期、每日8个时次、14个变量、lev坐标、单位和经纬度。文件存在并不代表可以复用，校验失败或配置不一致的文件不能静默作为输入。原始文件按区域和年份保留，以便中断恢复和后续复算。

当前脚本先将所选年度日文件下载或复用至本地，再进入该年度计算。下载中断后，已通过检查的文件可复用；计算中断则从保留的日文件恢复或重算。关键是保留原始文件和检查记录，使网络阶段与数值计算阶段能够分别排查。

### 2.4 逐时次PM₁₀计算与年度组织

本研究并非从该产品直接读取已经命名为PM₁₀的下载结果，而是使用第72模式层的组分质量混合比和空气密度，在同一网格、同一时次进行计算。当前采用的文献组分方案如下，以S表示加权质量混合比：

```text
S = 1.375×SO4 + BCPHOBIC + BCPHILIC
```

```text
    + OCPHOBIC + OCPHILIC + DU001 + DU002 + DU003
```

```text
    + 0.74×DU004 + SS001 + SS002 + SS003 + SS004
```

```text
PM₁₀ = S × AIRDENS × 10⁹                         （1）
```

质量混合比的单位为kg kg⁻¹，与AIRDENS（kg m⁻³）相乘后为kg m⁻³，再乘10⁹转换为μg m⁻³。硫酸盐采用1.375系数，DU004采用0.74系数，其余列出组分的系数为1。该方案来自前期提供的学位论文第10页，完整书目和系数原始出处仍待补齐，不将其称为NASA统一发布的PM₁₀公式。总PM₁₀也不能直接等同于沙尘浓度。

计算前按文件内的实际时间排序，核对原生网格和区域覆盖，依据多边形覆盖网格中心的规则构建掩膜。随后逐日读取，每次提取一个时次的必要变量，完成式（1）计算后立即写入年度输出。必要输入缺失时保留缺失，不当作零组分；区域外网格设置为缺失，区域内异常值单独记录。

这里的“按年合并”具体是：将每日算得的PM₁₀场按时间顺序沿time维追加至年度NetCDF4。当前流程没有先把全部原始组分合成一个年度大文件再计算，也没有把3小时时次改为日均或月均。因此，合并改变的是文件组织粒度，而不是原始时间分辨率。平年完整结果应为2920个时次，闰年为2928个时次；当前年份按实际截止时次核对。

该方式将内存需求限制在当前读取切片及缓冲区，避免一次加载全年14个变量。年度文件保留规则经纬度数组和区域掩膜；数组外形仍为矩形，并不表示把整个外接矩形作为研究区。写入结束后关闭句柄并重新读取校验，合格的临时文件再转为正式年度文件。

### 2.5 分层保存及其选择依据

本研究将任务记录、原始数据和派生结果分层管理。国内现有近地面PM₁₀流程按四省区联合范围组织年度网格；邻国版本按国家分目录，每个国家每年一个PM₁₀文件。原始日文件持续保留，城市或站点序列在匹配方法确定后另行提取（表4）。

**表4  文件层次、主要内容和保留理由**

| 文件层次 | 内容及组织 | 保留理由 |
| --- | --- | --- |
| 任务JSON与链接TXT | 区域、请求时间、变量、任务状态、到期信息及日文件地址 | 可查询任务、恢复清单和识别缺失；不是原始数值 |
| 原始日NetCDF | 14个输入变量及原始坐标，按日保存 | 可核查组分、调整计算方案和复算，无需重复下载 |
| 年度PM₁₀ NetCDF4 | 时间×纬度×经度的PM10，另含模式层标识、单位、掩膜和公式 | 按年份管理与按需读取，为不同点位匹配提供网格基础 |
| 后续城市／站点表格 | 按目标位置提取的多年序列，可导出CSV或Parquet | 便于观测配对、绘图和统计；点位资料尚需核实 |

年度NetCDF4适合同时保存多维网格和元数据，并可按时间或空间切片读取。它避免将经纬度、时间和多种变量全部重复展开为大型CSV；按年拆分又便于限定重算范围、检查单年缺失及后续扩展。只有少量目标点的序列再输出表格，更符合城市或站点分析的使用方式。

中间计算采用float64，年度PM₁₀以float32保存，并使用分块和zlib压缩。zlib对已存储的数值无损，但float64转float32本身存在舍入，不能把整个转换过程称为完全无损。存储设置服务于文件体积和读取需求，不改变格点坐标或3小时时次。具体参数列于附录，便于复现。

逐时次读取用于控制运行内存，变量筛选与压缩存储用于控制磁盘占用。现阶段同时保留原始日文件和派生结果，以增加一定存储占用换取输入可核查、方案可复算的能力；待目标点位确定后，日常分析可主要使用提取后的轻量序列。

这种分层保留使后续修改有明确入口：只更换城市或匹配方法时，从年度PM₁₀重新提取；改变组分公式时，从原始变量重新计算。无需为了每次点位调整重新向NASA申请全部原始资料。

### 2.6 完整性判断与后续使用边界

**表5  各阶段的完成条件和记录重点**

| 阶段 | 完成条件 | 需保留的检查信息 |
| --- | --- | --- |
| 链接准备 | 任务状态与请求一致，日期连续且无重复 | 地区、年份、job_id、起止时次、链接数、有效期 |
| 实体数据 | 所需日文件齐备且内容检查通过 | 文件校验和、变量、层次、坐标和日内时次 |
| 年度计算 | PM₁₀覆盖预期时间范围并完成写入校验 | 时次总数、完整自然年标识、区域内缺失与负值、数值范围及输出校验和 |

须区分“请求范围内已经完成”和“完整自然年”：例如当前年份可以完成截至最新可用日的计算，但仍不是全年资料。程序中的时间完整性也不等于区域内每个格点均无缺失，缺失和异常统计需要另外查看。对已有合格结果执行跳过，对不完整或配置不一致结果保留记录并处理，不以文件名存在代替检查。

年度文件以UTC年份组织，后续可增加当地时间。城市或站点匹配需要核实输入坐标、保留匹配网格和距离，并统一观测的时间统计尺度。本稿明确可用于提取的数据基础，具体匹配方法、观测来源及基于实际观测的精度评价另行展开。
