# MERRA-2近地面PM₁₀数据构建与时空匹配方法

方法部分修订稿 V3｜2026年10月21日

本研究利用MERRA-2气溶胶再分析资料，计算中国四省区及七个邻国的近地面PM₁₀，并提取城市点位的多年时间序列。处理过程依次包括数据选取、原始资料下载、PM₁₀计算与保存，以及点位时空匹配。下载阶段获得组分与空气密度日文件，计算阶段生成年度PM₁₀网格，匹配阶段将网格值提取为各城市的时间序列。

## 1 数据来源与研究范围

### 1.1 MERRA-2资料概况

MERRA-2（Modern-Era Retrospective Analysis for Research and Applications, Version 2）是美国国家航空航天局（NASA）全球建模与同化办公室（GMAO）开发的第二代现代时期研究与应用回顾分析资料，由GEOS模式及资料同化系统生成，通过NASA GES DISC提供访问和分发。该资料结合数值模式与观测约束，提供长期、连续的大气与气溶胶场，适用于多年和跨区域分析[1—3]。

本研究选用M2I3NVAER 5.12.4数据集，对应文件标识inst3_3d_aer_Nv。该数据集提供三维气溶胶组分质量混合比及空气密度，可在相同时间、格点和模式层上获取计算所需变量，从而估算近地面颗粒物浓度。再分析资料具有模式网格的空间代表尺度，其估算结果仍需与独立地面观测比较，以评价在研究区域的适用性。

### 1.3 研究区域与时间范围

国内研究区域包括宁夏、新疆、甘肃和内蒙古四省区；国外范围包括蒙古国、哈萨克斯坦、吉尔吉斯斯坦、塔吉克斯坦、阿富汗、巴基斯坦和印度七国。国内采用geoBoundaries的CHN ADM1省级边界，国外采用Natural Earth v5.1.2的1:50m国家级边界，按对应区域多边形请求数据并建立掩膜[4—5]。两套边界的来源、层级和概化程度不同，边界版本与文件校验信息分别保留，以便复现实际处理范围。

本阶段重点获取2015年至NASA最新实际可用日期的数据。资料存在发布滞后，截止时间以NASA目录为准；各地区已经下载和计算的范围，以本地有效文件及运行记录为准。后续与地面观测比较的时段，由两类数据共同具有有效记录的时间范围确定。

### 1.4 PM₁₀计算所需变量

从第72模式层选取14个变量，包括13个气溶胶组分质量混合比和空气密度AIRDENS（表2）。质量混合比表示单位质量空气中所含的组分质量，单位为kg kg⁻¹；与空气密度结合并进行单位换算后，可得到单位体积空气中的质量浓度。

**表2  PM₁₀计算所需的14个变量**

| 变量名称 | 物理含义 | 单位 |
| --- | --- | --- |
| AIRDENS | 空气密度 | kg m⁻³ |
| SO4 | 硫酸盐气溶胶质量混合比 | kg kg⁻¹ |
| BCPHOBIC、BCPHILIC | 疏水性、亲水性黑碳质量混合比 | kg kg⁻¹ |
| OCPHOBIC、OCPHILIC | 疏水性、亲水性有机碳质量混合比 | kg kg⁻¹ |
| DU001—DU004 | 第1至第4粒径档沙尘质量混合比 | kg kg⁻¹ |
| SS001—SS004 | 第1至第4粒径档海盐质量混合比 | kg kg⁻¹ |

## 2 原始数据下载与质量控制

原始数据通过NASA GES DISC获取。处理时先调用Harmony服务完成区域子集，再根据返回的链接下载实体文件。本地保存的原始日文件包含组分、空气密度及相应坐标，是后续PM₁₀计算的输入。

### 2.1 子集请求与逐日链接获取

完成Earthdata Login认证及必要授权后，Python程序按区域和年份提交子集请求，限定研究多边形、表2所列变量、第72模式层和时间范围。完整历史年采用UTC 1月1日00时至12月31日21时；当前年份按最新实际可用的完整日确定截止。通过筛选变量、垂直层次和空间范围，减少全球三维资料中与研究无关的数据传输。

NASA完成处理后，程序读取全部结果页，提取逐日NetCDF地址，写入年度TXT清单；同时以JSON保存请求条件、任务编号、状态和结果到期时间。写出清单前检查任务是否成功、日期是否连续以及有无重复，确认链接覆盖实际请求范围。服务端进度达到100%仍需核对最终状态，不能仅据进度认定结果完整。

TXT保存下载地址，JSON保存任务信息，两者用于后续下载与来源追溯。链接清单按区域和年份归档，年代文件夹仅用于管理，不改变日文件的时间组织方式。

### 2.2 下载链接的有效期

Harmony返回的data_expiration记录本次临时子集结果在NASA端的保存截止时间。各任务按自己的到期时间安排下载，同时分别记录资料覆盖时段和清单生成时间。获取链接后应及时下载，并在到期前补齐缺失文件。

例如，巴基斯坦2026年任务日志记录的到期时间为2026年11月20日05:34:09.037（UTC），对应北京时间当日13:34:09.037。该时间适用于这一次任务的临时结果，与资料覆盖到哪一天、本地文件能够保存多久分别管理。

链接到期且本地仍缺少文件时，应重新取得相应子集结果的有效链接。已经完整下载并校验通过的日文件可继续离线使用，后续PM₁₀计算与点位匹配也可直接使用本地文件。

### 2.3 文件下载与输入检查

下载程序读取年度清单，复用已有合格文件，仅下载缺失或校验失败的部分。账号密码在每次启动程序时按需输入一次，并在本次运行的各地区和年份间复用；完成首次认证后并发下载其余文件。

文件下载后检查传输长度、校验信息及NetCDF可读性，随后核查文件日期、日内时次、变量、单位、lev坐标和经纬度一致性。完整日应有8个时次，完整历史年应有365或366个日文件。只有通过检查的文件才进入计算；仅有同名文件不作为下载完成的依据。

原始日文件按地区和年份保存，并保留校验记录。中断后重新运行时，合格缓存可以继续使用，其他已完成的地区和年份保持有效，从而减少重复下载。

## 3 近地面PM₁₀计算与结果保存

PM₁₀由同一时次、同一格点和第72模式层的气溶胶组分及空气密度计算得到。处理顺序为组分换算、逐时次计算、年度合并与结果检查，最终形成可以重复用于点位提取的年度浓度网格。

### 3.1 计算公式与单位换算

采用已选定文献中的组分估算方案[6]，以S表示加权质量混合比，计算式为：

```equation
S = 1.375×SO4 + BCPHOBIC + BCPHILIC
    + OCPHOBIC + OCPHILIC + DU001 + DU002 + DU003
    + 0.74×DU004 + SS001 + SS002 + SS003 + SS004
PM₁₀ = S × AIRDENS × 10⁹                         （1）
```

式（1）中，硫酸盐项系数为1.375，DU004项系数为0.74，其余列出组分的系数为1。S的单位为kg kg⁻¹，与AIRDENS（kg m⁻³）相乘后为kg m⁻³，再乘10⁹转换为μg m⁻³。公式中的变量与表2逐一对应。

计算结果包含硫酸盐、黑碳、有机碳、沙尘和海盐等组分贡献，是所用估算方案下的总PM₁₀。分析沙尘贡献时，需另行计算其中的沙尘部分。公式系数的完整文献依据尚待补齐，具体情况列于参考资料[6]。

### 3.2 逐时次计算方法

首先读取日文件中的时间、经纬度和层坐标，确认各文件网格一致、实际层值为72，并按时间排序。保留原生网格，以网格中心是否被研究多边形覆盖确定有效区域，区域外设置为缺失值。

随后逐日读取数据，在每个时次提取14个变量的同位置切片，按式（1）生成该时次的PM₁₀场，计算后立即写入输出。这样可以在保留原始时间和空间分辨率的同时，将内存需求限制在当前切片及读写缓冲区，无需一次加载全年变量。

必要组分缺失或为非有限数值时，对应浓度保留为缺失值；空气密度出现有限但非正值时停止并核查。负PM₁₀保留并单独统计，避免以补零或截断掩盖异常。

### 3.3 年度合并与保存方式

年度合并在计算过程中完成：将每天算得的8个PM₁₀场按时间先后沿time维写入同一年度文件，形成PM10(time, lat, lon)。该过程保留原始3小时时次，不进行日均或月均处理，也无需先合并全年原始组分。

国内四省区按联合范围保存年度网格，邻国按国家分别保存，每个国家每年一个文件。年度文件采用NetCDF4，共同保存浓度、时间、经纬度、模式层、单位、区域掩膜和计算公式。经纬度数组保持规则矩形结构，有效研究范围由区域掩膜标识。

选择“地区—年份”组织方式，便于逐年检查、补充和重算；采用NetCDF4则便于保存多维网格及元数据，并按需读取局部时间或空间切片。计算采用float64中间精度，浓度以float32分块压缩保存，具体参数见附录A。原始组分日文件继续保留，以便调整公式后复算；仅改变目标点位时，可直接从年度PM₁₀网格重新提取。

### 3.4 计算结果的质量检查

年度结果完成后，首先检查时间轴的起止时刻、3小时间隔及重复或缺失情况。完整平年应有2920个时次，闰年应有2928个时次；当前年份或连续片段按实际请求时段检查，并记录是否覆盖完整自然年。

其次核查浓度变量的维度、坐标、单位和区域掩膜，统计区域内缺失值、负值及有效值范围。时间连续仅说明时次覆盖满足要求，格点数值是否缺失或异常需分别判断。

结果先写入临时文件，关闭后重新读取检查，通过后再保存为正式年度文件，并保留输入和输出校验信息。再次运行时，检查通过且计算配置一致的年度结果可以跳过。

## 4 城市点位PM₁₀的时空匹配

点位匹配以年度PM₁₀网格和城市坐标表为输入，先确定每个城市对应的原生格点，再按时间提取浓度，形成城市多年序列。当前国内已实现这一提取流程；与地面观测的时间配对规则，需在观测资料的时间定义核实后确定。

### 4.1 城市点位资料

现有city四省表包含45条记录，保存城市名称、编号、所属省区及经纬度。本研究据此建立点位索引，检查编号是否重复、坐标是否在合理范围，并核对点位位置。当前程序按十进制度读取输入坐标，未进行坐标基准转换。

该表的坐标来源、参考坐标系及具体代表位置尚需核实，因此本文称其为“城市点位”，暂不认定为城市中心或空气质量监测站。后续采用站点观测时，应使用经确认的站点代码及坐标；国外点位扩展也需先完成相同核查。

### 4.2 空间匹配方法

空间匹配采用原生格点中心的球面最近邻方法。对每个城市点，计算其与MERRA-2原生格点中心的球面距离，选择距离最小的格点，建立固定对应关系，并保存城市坐标、格点坐标、格点编号及距离。距离采用Haversine公式，具体表达式见附录B。

建立对应关系后，检查该格点是否包含在本地文件中、是否具有有效浓度。对于边界附近点位，最近格点可能位于现有裁剪范围或掩膜之外，应核查并补充所需网格；程序不自动改用区域内更远的格点。

最近邻提取直接使用所选格点值，不进行空间插值。受网格分辨率限制，多个城市可能对应同一格点，需在结果中保留各自标识并记录这一情况。格点与城市之间的距离用于检查空间代表性，提取值表征该格点尺度的浓度，城市内部差异仍需借助更细尺度资料分析。

### 4.3 时间对应方法

首先依据文件内的time单位和日历解析模式时刻，统一保留UTC时间，并核对时间戳唯一、递增且保持3小时间隔。国内城市另输出北京时间（UTC+8），便于与国内观测记录核对。年度网格以UTC年份组织，按当地日期统计时需处理跨日和跨年的时刻。

国外点位沿用UTC作为共同索引，当地时间按点位对应时区转换。与地面观测配对前，需确认观测时区、时间戳所指的采样时段，以及数据属于瞬时值、小时均值还是日均值，再确定共同的比较时间尺度。

当前已完成模式3小时时次的提取和时间转换，尚未实施观测窗口配对及日统计。后续若比较日尺度数据，应统一日界，分别规定模式样本和观测样本的聚合与完整性要求；8个模式瞬时值形成的日统计属于采样近似，需要在比较方法中说明。具体配对窗口和有效样本要求待观测资料核实后统一确定。

### 4.4 匹配结果保存与检查

按城市提取匹配格点的全部时次，依年份顺序组织为多年CSV，并按所属省区归档；另保存城市与格点映射表。已有年度网格可直接重复用于不同点位提取，国内原始日文件也支持在相同格点计算，补充实现说明见附录A。

**表3  城市PM₁₀序列的主要信息**

| 信息类别 | 保存内容 |
| --- | --- |
| 城市信息 | 城市编号、名称、所属地区、输入经纬度 |
| 匹配位置 | 格点经纬度、格点编号、城市至格点距离 |
| 时间与浓度 | UTC时间、北京时间、PM₁₀及其单位 |
| 计算说明 | 模式层标识、缺失或负值等质量标记 |

输出后检查城市是否齐全、时间覆盖是否符合输入范围，以及重复时刻、缺失值和异常值情况。完整年度的记录数与第3.4节规定一致。重复处理同一年时按UTC时间戳更新记录，避免重复追加。坐标改变后重新建立格点对应关系并提取；公式改变时先重新计算PM₁₀，再更新点位序列。不同配置分别保留记录。

通过上述检查表明点位提取和文件组织符合要求；估算值与地面实测的一致性，还需在观测配对完成后另行评价。

## 附录B 球面距离计算

设城市点为p、网格中心为g，纬度和经度分别为φ、λ，均以弧度参与计算，则：

```equation
a = sin²[(φg−φp)/2] + cosφp cosφg sin²[(λg−λp)/2]
d(p,g) = 2R arcsin(√a)，  g* = argmin_g d(p,g)       （2）
```

式（2）中，R取6371.0088 km，g*为最近格点。匹配时在完整原生网格上确定最近中心，再检查本地文件覆盖，避免裁剪范围改变最近邻选择。原生经度为−180°起、间距0.625°，纬度为−90°起、间距0.5°。当前未设统一的最大匹配距离阈值，距离随映射关系保留，用于后续代表性核查。
