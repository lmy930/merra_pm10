# MERRA-2近地面PM₁₀数据构建与时空匹配方法

方法部分修订稿 V4｜2026年10月21日

本研究利用MERRA-2气溶胶再分析资料，计算中国四省区及七个邻国的近地面PM₁₀，并提取城市点位的多年时间序列。处理过程依次包括数据选取、原始资料下载、PM₁₀计算与保存，以及点位时空匹配。下载阶段获得组分与空气密度日文件，计算阶段生成年度PM₁₀网格，匹配阶段将网格值提取为各城市的时间序列。

## 1 数据来源与研究范围

### 1.1 MERRA-2资料概况

MERRA-2（Modern-Era Retrospective Analysis for Research and Applications, Version 2）是美国国家航空航天局（NASA）全球建模与同化办公室（GMAO）开发的第二代现代时期研究与应用回顾分析资料，由GEOS模式及资料同化系统生成，通过NASA戈达德地球科学数据与信息服务中心（GES DISC）提供访问和分发。该资料结合数值模式与观测约束，提供长期、连续的大气与气溶胶场，适用于多年和跨区域分析[1—3]。

本研究选用M2I3NVAER 5.12.4数据集，对应文件标识inst3_3d_aer_Nv。该数据集提供三维气溶胶组分质量混合比及空气密度，可在相同时间、格点和模式层上获取计算所需变量，从而估算近地面颗粒物浓度。原始下载文件保存的是组分与空气密度，PM₁₀由后续计算得到。再分析资料具有模式网格的空间代表尺度，其估算结果仍需与独立地面观测比较，以评价在研究区域的适用性。

### 1.3 研究区域与时间范围

国内研究区域包括宁夏、新疆、甘肃和内蒙古四省区；国外范围包括蒙古国、哈萨克斯坦、吉尔吉斯斯坦、塔吉克斯坦、阿富汗、巴基斯坦和印度七国。国内采用geoBoundaries的CHN ADM1省级边界，国外采用Natural Earth v5.1.2的1:50m国家级边界，按对应区域多边形请求数据并建立掩膜[4—5]。两套边界的来源、层级和概化程度不同，边界版本与文件校验信息分别保留，以便复现实际处理范围。

本阶段重点获取2015年至NASA最新实际可用日期的数据。资料存在发布滞后，截止时间以NASA目录为准；各地区已经下载和计算的范围，以本地有效文件及运行记录为准。后续与地面观测比较的时段，由两类数据共同具有有效记录的时间范围确定。

### 1.4 PM₁₀计算所需变量

计算选取第72模式层的14个变量，包括13个气溶胶组分质量混合比和空气密度AIRDENS（表2）。质量混合比表示单位质量空气中所含的组分质量，所列变量与第3章的组分计算方案对应。

**表2  PM₁₀计算所需的14个变量**

| 变量名称 | 物理含义 | 单位 |
| --- | --- | --- |
| AIRDENS | 空气密度 | kg m⁻³ |
| SO4 | 硫酸盐气溶胶质量混合比 | kg kg⁻¹ |
| BCPHOBIC、BCPHILIC | 疏水性、亲水性黑碳质量混合比 | kg kg⁻¹ |
| OCPHOBIC、OCPHILIC | 疏水性、亲水性有机碳质量混合比 | kg kg⁻¹ |
| DU001—DU004 | 第1至第4粒径档沙尘质量混合比 | kg kg⁻¹ |
| SS001—SS004 | 第1至第4粒径档海盐质量混合比 | kg kg⁻¹ |

## 2 原始数据获取与质量控制

### 2.1 区域子集与链接获取

通过Earthdata Login认证后，使用Python调用NASA Harmony服务，按区域和年份提交子集请求，限定研究多边形、表2所列变量和第72模式层。历史完整年覆盖UTC 1月1日00时至12月31日21时，最新年份截至NASA目录实际可用时次。预先筛选区域、变量和层次，可减少全球三维资料中无关数据的传输。

服务端完成处理后，提取逐日NetCDF文件地址，写入年度TXT；同时以JSON记录请求条件、任务编号、状态和到期时间。只有任务成功且逐日链接覆盖请求时段、无缺失或重复时，才将其作为完整下载清单。

### 2.2 实体文件下载与有效期管理

下载程序读取年度TXT，按地区和年份保存原始日文件。每次运行按需输入一次账号密码，完成认证后并发下载，已有合格文件优先复用。

Harmony子集结果具有临时保存期限，以任务返回的到期时间安排下载。到期后尚未下载的部分需重新取得有效链接；已经完整保存并通过校验的本地文件可继续使用。具体到期时间示例及任务追溯信息列于附录。

### 2.3 原始数据完整性检查

下载后检查文件完整性及NetCDF可读性，再核对日期、日内时次、14个变量、单位、层坐标和经纬度。完整日应包含8个时次，完整历史年应有365或366个日文件；最新年份按实际请求范围核对。通过检查的文件进入计算，并保留校验记录，支持中断恢复和后续复算。

## 3 近地面PM₁₀计算与结果保存

### 3.1 组分计算公式

在相同格点、时次和模式层上，采用选定文献的组分估算方案[6]。以S表示加权质量混合比，计算式为：

```equation
S = 1.375×SO4 + BCPHOBIC + BCPHILIC
    + OCPHOBIC + OCPHILIC + DU001 + DU002 + DU003
    + 0.74×DU004 + SS001 + SS002 + SS003 + SS004
PM₁₀ = S × AIRDENS × 10⁹                         （1）
```

S的单位为kg kg⁻¹，与AIRDENS（kg m⁻³）相乘得到kg m⁻³，再乘10⁹转换为μg m⁻³。硫酸盐项系数为1.375，DU004项系数为0.74，其余列出组分的系数为1。该结果包含多类气溶胶贡献，表示所用方案下的总PM₁₀；沙尘贡献需单独提取。公式文献的完整书目信息仍待补齐，见参考资料[6]。

### 3.2 逐时次计算

读取原始日文件，核对时间、经纬度及lev=72，按时间顺序逐日处理。保留原生网格，以网格中心是否被研究多边形覆盖建立掩膜；对每个时次读取14个变量，按式（1）计算并写入PM₁₀场。这种逐时次处理方式可控制内存占用，避免一次加载全年变量。

区域外和必要输入缺失的位置保留为缺失值；空气密度出现有限但非正值时停止核查，负PM₁₀单独记录，避免将异常值直接改为零。

### 3.3 年度合并与保存依据

每日算得的PM₁₀场依次沿时间维写入年度NetCDF4，形成“时间×纬度×经度”数组，保留原始3小时时次。年度合并在计算过程中完成，不进行日均或月均处理。国内按四省区联合范围组织，邻国按国家分别保存，每个国家每年一个文件。

NetCDF4可共同保存浓度、坐标、单位、模式层、区域掩膜和计算公式，并支持局部读取；按地区和年份组织便于检查、补充和重算。原始日文件继续保留，供调整公式后复算；更换城市点位时则直接从年度网格重新提取。具体存储参数见附录。

### 3.4 计算结果检查

检查年度时间轴的起止、3小时间隔及重复或缺失情况：完整平年为2920个时次，闰年为2928个时次，片段结果按实际范围核对。同时核查坐标、单位和掩膜，统计区域内缺失值、负值及有效值范围。输出文件重新读取检查通过后保存为正式结果；时间覆盖完整与数值无缺失分别判断。

## 4 城市点位PM₁₀的时空匹配

### 4.1 点位资料与坐标核查

国内采用现有city四省表的45条记录，以城市编号、名称、所属省区和经纬度建立点位索引，检查重复编号及位置合理性。当前程序按十进制度读取坐标，未转换坐标基准。坐标来源、参考坐标系及其代表位置尚需核实，因此称为“城市点位”，暂不认定为城市中心或空气质量监测站；国外点位扩展需完成相同核查。

### 4.2 空间匹配

采用球面最近邻方法，在MERRA-2完整原生网格上寻找距离城市点最近的格点中心，保存点位坐标、格点坐标、编号及距离，并在不同年份沿用这一映射。距离采用Haversine公式，表达式见附录。

确定最近格点后，检查本地文件覆盖和数值有效性。边界附近若缺少所需格点，应核查并按需补充，不自动换用区域内更远格点。多个城市对应同一格点的情况予以保留；匹配值代表相应网格尺度，不能反映城市内部的细微差异。

### 4.3 时间对应

模式时刻按文件内时间单位和日历解析为UTC，国内另输出北京时间（UTC+8）。年度网格按UTC年份组织，按当地日期分析时处理跨日、跨年问题；国外扩展按点位实际时区转换。

与地面观测比较前，需核实观测时区、采样时段和统计周期，再确定共同时间尺度。当前已实现模式3小时时次提取与时间转换，观测配对窗口及有效样本要求尚待确定。若采用日尺度比较，应统一日界，并说明由8个模式瞬时样本形成的日统计属于采样近似。

### 4.4 序列保存与匹配检查

按城市提取对应格点的多年浓度，保存为CSV并按省区归档，另存格点映射表。结果保留城市信息、原始及匹配坐标、距离、时间、浓度、单位和质量标记，便于追溯。

检查点位齐全性、时间覆盖、重复时刻及缺失和异常值。更新同一年时按UTC时间戳合并，避免重复追加；坐标变化后重新匹配，公式变化则先重算PM₁₀再更新序列。观测比较和精度评价在时空配对规则确定后另行开展。

**表A1  数据组织与主要实现参数**

| 项目 | 当前设置或记录 |
| --- | --- |
| 任务与链接 | 按国家、年代、年份归档JSON与TXT；记录请求条件、任务编号、状态、清单写出时间及结果到期时间 |

| 城市序列 | 按省区保存城市_PM10.csv，另存city_grid_mapping.csv及配置记录 |
| 结果追溯 | 保留边界版本、公式、输入文件校验、时次覆盖、异常统计及输出校验 |

zlib对已存储数值进行无损压缩，float64转float32本身存在舍入。任务记录和链接用于来源追溯，原始组分支持复算，年度网格支持不同点位重复提取，城市序列用于后续统计与观测比较。

有效期示例：巴基斯坦2026年任务记录的到期时间为2026-11-20 05:34:09.037 UTC，对应北京时间当日13:34:09.037。该日期仅用于该次临时结果的下载安排，其他任务读取各自记录。

球面距离计算：设点位p与格点g的纬度、经度分别为φ、λ，均以弧度计算，R取6371.0088 km，则：

```equation
a = sin²[(φg−φp)/2] + cosφp cosφg sin²[(λg−λp)/2]
d(p,g) = 2R arcsin(√a)，  g* = argmin_g d(p,g)       （2）
```

其中g*为最近格点，距离随点位映射保留，用于检查空间代表性。
