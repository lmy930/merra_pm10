# MERRA-2近地面PM₁₀数据构建与时空匹配方法

方法部分修订稿 V2｜2026年10月21日

本研究利用MERRA-2气溶胶再分析资料，构建中国四省区及七个邻国的近地面PM₁₀网格数据，并为城市或监测站点提取时间序列。报告按照“数据选择—原始数据获取—浓度估算与年度数据构建—点位时空匹配”展开：第1章说明数据来源和研究范围，第2章说明如何获得合格的原始输入，第3章说明如何由组分生成并保存PM₁₀，第4章说明如何将网格结果与目标位置、观测时间对应。

## 1 数据来源与研究范围

### 1.1 MERRA-2资料及产品选择

MERRA-2（Modern-Era Retrospective Analysis for Research and Applications, Version 2）是美国国家航空航天局（NASA）全球建模与同化办公室（GMAO）开发的第二代现代时期研究与应用回顾分析资料，由GEOS模式及资料同化系统生成，通过NASA GES DISC提供访问和分发。该资料结合数值模式与观测约束，形成长期、连续的大气与气溶胶场，适用于采用统一数据来源开展多年和跨区域分析[1—3]。

本研究采用M2I3NVAER 5.12.4产品，对应文件标识inst3_3d_aer_Nv。该产品在一致的时空坐标下提供三维气溶胶组分质量混合比及空气密度，可提取底部模式层，为近地面PM₁₀估算提供相互对应的输入。选择这一产品的依据是组分信息、垂直层次和时间组织与本研究计算方案相适应；派生PM₁₀的准确性仍需通过独立地面观测评价。

### 1.3 研究区域与时间范围

国内研究范围包括宁夏、新疆、甘肃和内蒙古四省区；国外扩展范围包括蒙古国、哈萨克斯坦、吉尔吉斯斯坦、塔吉克斯坦、阿富汗、巴基斯坦和印度七国。国内采用geoBoundaries的CHN ADM1省级边界，国外采用Natural Earth v5.1.2的1:50m国家级边界。请求和本地掩膜使用对应区域多边形，并保留边界版本及文件校验信息[4—5]。

行政边界用于限定区域数据的组织范围，城市点位的空间匹配另按第4章的方法完成。尤其在边境、沿海及岛屿地区，边界概化可能影响局部网格覆盖，须针对目标点检查所需格点是否可用。两套边界来自不同资料体系，其行政层级和概化程度分别记录，不统称为各国政府发布的官方边界。

本阶段重点获取2015年至NASA最新实际可用日期的数据，以衔接后续地面观测。产品存在发布滞后，最新截止时间需查询NASA目录；实际已完成范围则以各地区、各年份的有效文件和运行记录为准。产品自1980年起的覆盖、本研究计划获取范围和已完成范围分别表述，最终与观测比较的年段由两类数据的共同有效覆盖确定。

### 1.4 计算所需变量与垂直层次

本研究选取第72模式层的14个变量，其中13个为气溶胶组分质量混合比，1个为空气密度。变量集合与第3章的组分估算方案对应，具体名称及单位见表2。读取时依据文件内lev坐标确认层值为72，避免仅凭数组下标判断垂直层次。

**表2  近地面PM₁₀估算所用输入变量**

| 变量名称 | 物理含义 | 单位 |
| --- | --- | --- |
| AIRDENS | 空气密度 | kg m⁻³ |
| SO4 | 硫酸盐气溶胶质量混合比 | kg kg⁻¹ |
| BCPHOBIC、BCPHILIC | 疏水性、亲水性黑碳质量混合比 | kg kg⁻¹ |
| OCPHOBIC、OCPHILIC | 疏水性、亲水性有机碳质量混合比 | kg kg⁻¹ |
| DU001—DU004 | 第1至第4粒径档沙尘质量混合比 | kg kg⁻¹ |
| SS001—SS004 | 第1至第4粒径档海盐质量混合比 | kg kg⁻¹ |

质量混合比表示单位质量空气中所含的组分质量。通过空气密度将其转换为单位体积浓度，并结合相应组分权重，才能获得本研究使用的近地面PM₁₀估算值。

## 2 MERRA-2原始数据获取与质量控制

本章的目标是获得覆盖请求时段、包含必要变量且能够直接用于计算的本地原始日文件。数据获取分为服务端子集处理与本地实体下载两个环节；年度TXT用于连接两者，任务JSON用于保留请求依据和结果状态。

### 2.1 区域子集请求与下载清单生成

通过Earthdata Login认证后，Python程序调用NASA Harmony子集服务，按处理区域和年份提交请求。请求条件包括研究多边形、14个变量、第72模式层及时间范围。完整历史年采用UTC 1月1日00时至12月31日21时；当前年份按目录最新实际可用的完整日确定截止。预先限制空间范围、垂直层和变量，可以减少无关全球三维资料的传输与保存。

服务端完成子集处理后，程序读取结果列表及其分页，提取逐日NetCDF文件地址，整理为年度TXT清单。写出前检查任务状态和逐日日期覆盖，排除日期缺失、重复或与请求范围不符的结果；同时在JSON中保存请求条件、任务编号、状态和结果到期时间。进度达到100%仅表示服务端处理结束，是否可作为完整输入仍由任务结果与日期检查共同确定。

下载清单按区域、年份管理，年代文件夹仅用于归档。清单生成完成表示已获得实体文件的访问地址，原始数值是否已经下载到本地，须由后续下载及文件校验结果判断。

### 2.2 临时子集结果的有效期管理

Harmony返回的data_expiration表示本次临时子集结果在NASA端的保存截止时间。该时间用于安排下载，与资料本身的覆盖时段分别记录；清单生成日期也不能替代到期时间。各任务的有效期以其返回记录为准，不统一假定固定保存天数。

以巴基斯坦2026年任务日志为例，其结果到期时间为2026年11月20日05:34:09.037（UTC），对应北京时间当日13:34:09.037。这个日期只约束该次任务结果的后续访问，不表示2026年资料已覆盖全年，也不决定本地文件能够使用多久。

获取清单后应及时下载，并在到期前优先补齐缺失文件。若结果已经过期且本地仍缺数据，应恢复或重新生成相应子集结果，再更新待下载清单。已经完整下载并校验通过的日文件可以继续离线使用，年度PM₁₀和点位序列也不随临时链接到期失效，因此无需因到期而重复下载全部数据。

### 2.3 原始文件下载、校验与复用

下载程序读取年度TXT，先检查本地缓存，仅下载缺失或未通过检查的文件。账号密码在每次启动程序时按需输入一次，认证信息在本次运行内供后续国家和年份复用。完成首个缺失文件的认证后，并发下载其余文件；下载速度取决于服务端响应、网络及本地读写条件。

原始文件的验收同时检查传输完整性和数据内容：前者核查文件长度、校验信息及NetCDF可读性，后者核查日期、日内时次、必要变量、模式层、单位和经纬度一致性。完整日应有8个3小时时次；完整历史年对应365或366个日文件。发现内容异常时保留错误记录，不仅依据文件名存在就判定下载完成。

校验通过的日文件按地区和年份保存，作为第3章计算的输入。再次运行时优先复用合格文件；某个地区或年份尚未完成，不影响其他已完成结果的保留。由此，网络获取与本地计算可以分别恢复和排查，避免因短时网络故障重复获取已有数据。

## 3 近地面PM₁₀估算与年度数据构建

本章以校验后的日文件为输入，在同一格点和时次上完成组分换算，生成保留原始3小时时次的年度PM₁₀网格。计算方案、时间拼接和文件保存分别说明，以区分物理量转换与数据组织方式。

### 3.1 气溶胶组分换算与浓度单位

设S为选定组分的加权质量混合比，当前采用的估算方案为：

```equation
S = 1.375×SO4 + BCPHOBIC + BCPHILIC
    + OCPHOBIC + OCPHILIC + DU001 + DU002 + DU003
    + 0.74×DU004 + SS001 + SS002 + SS003 + SS004
PM₁₀ = S × AIRDENS × 10⁹                         （1）
```

式（1）中，S的单位为kg kg⁻¹，AIRDENS的单位为kg m⁻³，二者相乘得到kg m⁻³，再乘10⁹转换为μg m⁻³。硫酸盐项的系数为1.375，第4粒径档沙尘项的系数为0.74，其余列出组分的系数为1。该结果包含硫酸盐、黑碳、有机碳、沙尘和海盐贡献，表示所用组分方案下的总PM₁₀估算值；若分析沙尘贡献，需要另行提取相应沙尘项。

当前系数方案依据前期提供的学位论文第10页实现。正式报告尚需补齐该论文作者、题名、年份及系数的原始文献依据；在完成核实前，将其表述为本研究采用的文献估算方案，不称为NASA直接发布的PM₁₀变量或统一公式。

### 3.2 原生网格保留与逐时次计算

计算前读取文件内的时间单位、日历、经纬度和层坐标，确认各日文件网格一致，并按实际时刻排序。本地处理保留原生经纬度网格，不重新投影或加密。以网格中心是否被研究多边形覆盖建立区域掩膜，掩膜外格点写为缺失值。

程序逐日读取数据，每次提取一个时次所需的14个输入切片，按式（1）计算PM₁₀，随后写入输出。必要组分缺失或非有限时保留缺失，不将缺失组分当作零；空气密度出现有限但非正值时停止并核查。负浓度单独统计，不静默截断为零。这些处理用于保留输入异常的信息，防止人为填补改变结果含义。

逐时次读取使内存占用主要由当前切片和读写缓冲决定，无需一次加载全年14个变量。区域结果仍采用规则经纬度数组：矩形数组是存储结构，实际有效范围由多边形掩膜限定，两者共同描述年度数据的空间覆盖。

### 3.3 年度时间拼接与结果验收

本研究的年度组织方式是“逐日计算、沿时间维写入”：每个日文件的8个时次依次生成PM₁₀场，再按先后顺序追加至PM10(time, lat, lon)。无需先将全年14个原始变量合成一个大型文件。年度拼接仅改变文件组织粒度，不进行日均或月均重采样。

写入后检查时间轴的起止时刻、间隔、重复与缺失，核对预期时次数。完整平年应为2920个时次，完整闰年应为2928个时次；当前年份或有意选取的连续片段按其实际请求范围验收，并记录是否覆盖完整自然年。同时统计区域内缺失值、负值及有效值范围，分别反映时间覆盖与数值质量。

年度输出先写临时文件，关闭后重新打开检查，合格后再转为正式文件，并保存输入指纹和输出校验信息。只有检查通过、配置一致的既有结果才跳过。因而“请求时段已经完成”“完整自然年”和“区域内无缺失值”是三个不同判断，不能仅由时次总数或文件名推定全部成立。

### 3.4 分层保存及文件组织依据

数据按任务记录、原始组分、年度网格和点位序列四层管理。国内现有年度网格覆盖四省区联合范围；邻国按国家分别保存，每个国家每年一个PM₁₀文件。不同层次的产物和用途见表3。

**表3  研究数据的保存层次及用途**

| 保存层次 | 主要内容 | 使用与保留依据 |
| --- | --- | --- |
| 任务与链接 | 请求JSON、年度逐日链接TXT、任务状态与有效期 | 追溯来源、恢复任务、识别待下载文件 |
| 原始组分 | 按地区和年份保存的逐日NetCDF文件 | 核查输入、调整公式和复算，减少重复下载 |
| 年度PM₁₀网格 | 浓度、时间、经纬度、模式层标识、区域掩膜和计算元数据 | 为不同目标点重复提取提供统一基础 |
| 城市或站点序列 | 点位与格点对应关系、逐时次PM₁₀及质量标记 | 便于多年统计、观测配对和绘图 |

年度网格采用NetCDF4，便于共同保存多维数组、坐标、单位与掩膜，并按需读取时间或空间切片。按年分文件可以限定重算范围、检查单年覆盖并逐年扩展。网格数据不全面展开为大型CSV，目标点提取后再按城市或站点保存轻量表格，使区域计算与点位分析各使用适合的文件组织。

中间计算采用float64，PM₁₀以float32保存，并使用分块及zlib压缩。zlib对已存储数值无损，但float64转float32存在舍入；具体参数列于附录A。现阶段保留原始日文件，以增加一定磁盘占用换取输入核查与公式复算能力。以后仅改变点位或空间匹配方法，可以从年度网格重新提取；改变组分公式时，则从保留的原始变量重新计算。

## 4 城市与监测站点的时空匹配方法

时空匹配将网格浓度转换为与目标位置、目标时刻对应的序列。本研究当前已实现国内给定城市点位与MERRA-2原生网格的最近邻提取及多年序列组织；点位身份核实、国外点位扩展和地面观测时间配对分别说明。只有空间位置、时区和时间统计尺度均明确后，才能形成用于观测比较的有效样本。

### 4.1 目标点位整理与坐标核查

现有city四省表共45条记录，包含省区、城市名称、编号和经纬度。仅凭一座城市对应一个坐标，不能判断其属于城市中心、代表位置或监测站；在资料来源核实前，本报告将其称为“给定城市点位”。当前程序按输入数值为十进制度处理，未进行坐标基准转换，正式比较前需确认坐标来源、表达格式和参考坐标系。

点位表至少保留唯一编号、名称、所属地区、经度和纬度，并检查编号重复、坐标范围及位置合理性。若后续使用空气质量监测站，增加站点代码、类型及有效时期，以处理同名城市多站和站点迁移。国外分析沿用相同字段和检查原则，但应先核实目标点位与坐标，不能将未经确认的城镇名录直接作为监测站资料。

### 4.2 原生网格的球面最近邻匹配

空间提取采用球面最近邻方法。对每个目标点，在MERRA-2完整原生水平网格上计算其到各格点中心的球面距离，选取距离最小的中心，建立固定的“目标点—格点”对应关系。距离采用Haversine公式计算：

```equation
a = sin²[(φg−φp)/2] + cosφp cosφg sin²[(λg−λp)/2]
d(p,g) = 2R arcsin(√a)，  g* = argmin_g d(p,g)       （2）
```

式（2）中，φ与λ分别为纬度和经度，计算时使用弧度；p为目标点，g为网格中心，R取6371.0088 km。当前原生网格经度为−180°起、间距0.625°，纬度为−90°起、间距0.5°。程序同时保存点位坐标、匹配格点坐标、格点编号和球面距离，使映射关系可以检查并在不同年份重复使用。

选定最近格点后，再检查本地文件是否包含该格点且其数值可用。边界裁剪可能使最近格点位于现有掩膜之外；这时应核查覆盖并按需补充局部数据，不自动改用区域内更远格点。最近格点的选择不附加“必须位于目标行政区内”的限制，行政边界用于管理数据，空间距离用于确定对应格点。

最近邻提取保留原生格点值，方法简单且便于复现，但不能刻画城市内部差异，也不意味着格点浓度等于站点实测。多个城市或站点可能匹配到同一格点，这是网格分辨率的结果；保留各自点位标识，分析时注意其序列并非相互独立的空间信息。匹配距离作为代表性检查依据，当前未设置统一的有效距离阈值。

### 4.3 时间基准统一与观测配对

模式时间首先按照文件的time单位和日历解码为UTC，检查时间戳唯一、递增且保持3小时间隔。点位提取保留UTC时间，国内同时输出北京时间（UTC+8）供展示。年度文件按UTC年份组织，因此转换后可能出现当地日期或年份跨界，统计时以事先明确的时间基准划分。

国外点位在扩展时应根据实际位置和资料说明确定时区，保留UTC作为共同索引；涉及多个时区或夏令时的地区，采用对应的时区规则，不能统一套用北京时间。观测资料还需核实时间戳是采样起点、终点还是区间代表时刻，以及浓度单位、有效性标记和统计周期。

与地面PM₁₀比较时，应先确定共同时间尺度。若开展3小时时次比较，应明确每个模式瞬时场对应哪一观测窗口；若开展日尺度比较，应统一日界，并分别规定模式3小时样本和观测样本的日统计及完整性要求。由8个模式瞬时样本形成的日统计是对当日状态的采样近似，不能直接称为连续24小时平均。

当前程序完成的是模式时次提取与时间转换，尚未实施地面观测窗口配对和日统计。具体配对规则及最低有效样本要求应在取得观测资料、核实其时间定义后确定，再统一执行；缺测不默认补零，也不在未说明的情况下插值补齐。

### 4.4 多年点位序列与匹配结果检查

已有年度PM₁₀时优先直接提取匹配格点的时间序列；也可从原始日文件的相同格点读取组分，按式（1）计算。两条路径使用相同网格和公式，但年度文件已经转换为float32，数值可能存在相应舍入差异。年度网格是便于重复提取的统一基础，并非点位计算必须额外完成的原始变量合并步骤。

国内现有程序按省区归档，每个城市保存一个可追加年份的CSV，同时输出独立格点映射表。表内保留城市标识、点位坐标、格点坐标及距离、UTC与北京时间、PM₁₀浓度、单位、模式层和质量标记。更新同一年时按UTC时间戳合并，避免重复追加；改变坐标或公式时需更新配置记录，避免将不同口径的结果混为一列。

匹配结果检查包括点位是否齐全、格点是否存在、时间覆盖是否符合要求，以及缺失值、负值和共用格点情况。完整平年每个点应有2920条模式记录，闰年应有2928条；片段结果按实际起止检查。质量标记用于说明数值是否缺失或为负，不能据其为正常值就认定估算准确。现有流程测试与最终观测精度评价分别记录，后者需在点位与时间配对规则确定后开展。
