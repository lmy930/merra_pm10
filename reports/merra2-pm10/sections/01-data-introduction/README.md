## 1  MERRA-2数据介绍

本研究拟利用MERRA-2气溶胶再分析资料构建研究区域近地面PM₁₀数据，为后续位置提取和地面观测比较提供统一的数据基础。数据选择需要同时满足气溶胶组分可用于浓度估算、具有近地面垂直信息，以及时间和空间覆盖能够支持跨区域分析三个条件。基于这些要求，本阶段选用M2I3NVAER 5.12.4产品，并保留其原始网格和3小时时间分辨率。

### 1.1 数据来源与基本性质

MERRA-2（Modern-Era Retrospective Analysis for Research and Applications, Version 2）是美国国家航空航天局（NASA）全球建模与同化办公室（GMAO）开发的第二代现代时期研究与应用回顾分析资料，由Goddard Earth Observing System（GEOS）模式及资料同化系统生成，并通过NASA Goddard Earth Sciences Data and Information Services Center（GES DISC）提供访问与分发[1—3]。

再分析资料通过数值模式与观测约束形成连续的时间和空间场，适合用于长期变化和区域比较。对于气溶胶研究，MERRA-2能够提供硫酸盐、黑碳、有机碳、沙尘和海盐等组分信息，以及相关大气状态变量，因此可作为组分法估算近地面颗粒物浓度的数据基础。其数值代表模式网格上的大气状态，与单个监测站的采样位置和代表范围不同，后续需要通过地面观测评价。

### 1.2 所用产品及其时空特征

本研究使用的产品简称为M2I3NVAER，版本为5.12.4，对应文件产品标识inst3_3d_aer_Nv。该产品为三维、3小时、瞬时、模式层气溶胶质量混合比产品。产品及关键参数见表1，其中水平网格间距按“经度×纬度”列示[1]。

**表1  M2I3NVAER产品的主要信息**

| 项目 | 详细信息 |
| --- | --- |
| 产品简称／版本 | M2I3NVAER／5.12.4 |
| 文件产品标识 | inst3_3d_aer_Nv |
| 主要物理量 | 气溶胶组分质量混合比及相关状态变量 |
| 产品时间覆盖 | 自1980年起；最新可用日期随数据发布更新 |
| 时间分辨率与性质 | 3小时瞬时值，每日8个时次 |

时间和垂直坐标直接决定后续数据的解释方式。首先，每个时次为瞬时值，不能直接称为相邻3小时的平均浓度。其次，第72层为底部模式层，可用于本研究的近地面估算，但不是固定离地高度或固定气压层，不能等同于地面仪器采样高度。再次，产品更新存在发布滞后，研究截止日期应以NASA目录实际提供的数据为准，不将当前年份默认视为完整全年。

### 1.3 本研究选取的变量与范围

为支持后续PM₁₀估算，本阶段选取第72模式层的14个变量，包括空气密度，以及硫酸盐、黑碳、有机碳、部分粒径档沙尘和海盐的质量混合比。质量混合比表示单位质量空气中相应组分的质量，尚不是单位体积空气中的浓度；空气密度用于后续质量混合比与质量浓度之间的换算。变量选择及单位见表2，具体组分权重另在计算方法部分说明。

**表2  本研究获取的14个变量**

| 变量名称 | 物理含义 | 单位 |
| --- | --- | --- |
| AIRDENS | 空气密度 | kg m⁻³ |
| SO4 | 硫酸盐气溶胶质量混合比 | kg kg⁻¹ |
| BCPHOBIC、BCPHILIC | 疏水性、亲水性黑碳质量混合比 | kg kg⁻¹ |
| OCPHOBIC、OCPHILIC | 疏水性、亲水性有机碳质量混合比 | kg kg⁻¹ |
| DU001—DU004 | 第1至第4粒径档沙尘质量混合比 | kg kg⁻¹ |
| SS001—SS004 | 第1至第4粒径档海盐质量混合比 | kg kg⁻¹ |

国内研究范围为宁夏、新疆、甘肃和内蒙古；国外扩展范围为蒙古国、哈萨克斯坦、吉尔吉斯斯坦、塔吉克斯坦、阿富汗、巴基斯坦和印度。现阶段重点获取2015年至最新实际可用日期的数据，以衔接后续可获得的地面观测；最终比较时段仍取决于观测资料的有效覆盖。空间和时间范围作为请求条件保存，便于日后扩展或复查。

### 1.4 数据下载方法

数据通过NASA GES DISC产品入口获取，访问和下载时使用Earthdata Login账户认证，并按服务提示完成授权。本研究通过Python调用Harmony子集服务，提交区域多边形、起止时间、变量及垂直层条件。该方式在传输前限定所需范围，避免先下载全球全部模式层再本地筛选，可减少不必要的下载和存储。国内区域依据所选省界组织，国外区域依据所选国家边界组织；边界版本随任务记录保留。

获取过程分为服务端子集处理和本地实体文件下载。服务端根据请求生成逐日结果，程序提取其下载地址并写入年度TXT清单，同时保存任务编号、请求范围、处理状态和结果有效期。本地下载程序再读取清单，将原始NetCDF日文件保存到相应区域和年份目录。因此，TXT是下载入口，任务JSON用于追溯，而.nc4文件才是后续读取和计算使用的实体数据。

原始文件下载采用并发与缓存复用：先完成首次认证，再获取缺失日文件；已有文件通过检查后直接复用。一个完整日应包含8个原始时次，历史完整年应有365或366个日文件。正式计算前检查日期连续性、变量、层次、单位及经纬度一致性。任务部分成功、日期缺失或返回非数据内容时，不将该年度标记为完整。临时链接具有保存期限，已下载到本地的完整文件可以继续使用，尚未下载的过期结果则需刷新链接。

### 1.5 数据读取与使用方式

NetCDF4以维度、变量和属性共同描述数据。使用时通过Python的netCDF4或xarray等工具读取文件，先识别时间、经纬度、垂直层、单位和缺失值，再按目标时间与空间范围提取变量。原始变量通常具有time、lev、lat、lon维度；区域子集在空间格点数上小于全球产品，选择第72层后也需确认文件实际返回的层次。不能只依据文件名或数组位置判断坐标含义。

本阶段先在原始网格上使用气溶胶组分和空气密度估算PM₁₀，再按区域和年份保存为NetCDF4，同时保留原始日文件。该组织方式保留完整空间信息，使后续更换城市、监测站或匹配方案时能够直接重新提取；如果计算方案调整，也可以利用原始变量复算。本地完整文件可直接离线读取，无需重新获取链接。具体PM₁₀公式及数值处理在后续计算部分展开。

开展城市或站点分析时，使用经核实的坐标匹配网格，保留目标坐标、网格坐标和匹配距离，并统一时间基准。原始时间为UTC，国内展示可换算为北京时间UTC+8；跨国比较需按分析目的明确使用UTC还是当地时间。由于原始数据为瞬时值，与小时或日均观测配对前还需明确统计尺度。经纬度匹配只能建立位置对应关系，不能消除网格尺度与站点尺度的差异。

PM₁₀网格结果保留后，点位时间序列可按城市或站点导出CSV、Parquet等表格。NetCDF4适合保存多维网格和元数据，CSV适合较小规模的位置序列，二者承担不同用途。总PM₁₀由多种气溶胶组分构成，若后续关注沙尘，还需区分总颗粒物浓度与沙尘组分。
