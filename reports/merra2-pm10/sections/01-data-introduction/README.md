## 1  MERRA-2数据介绍

本研究以MERRA-2气溶胶再分析资料为基础，构建研究区域近地面PM₁₀数据，为后续城市或监测站提取及地面观测比较提供统一的数据来源。所选资料需要同时具备可用于颗粒物估算的组分变量、近地面垂直信息，以及支持多年和跨区域分析的时空覆盖。基于上述要求，本阶段采用M2I3NVAER 5.12.4产品，获取所需区域和第72模式层数据，并保留原始水平网格与3小时时次。

### 1.1 数据来源与基本性质

MERRA-2（Modern-Era Retrospective Analysis for Research and Applications, Version 2）是美国国家航空航天局（NASA）全球建模与同化办公室（GMAO）开发的第二代现代时期研究与应用回顾分析资料，由Goddard Earth Observing System（GEOS）模式及资料同化系统生成，并通过NASA Goddard Earth Sciences Data and Information Services Center（GES DISC）提供访问与分发[1—3]。

MERRA-2通过数值模式与观测约束形成连续的大气和气溶胶场，其长期、统一的覆盖有利于在不同区域采用一致的数据和处理方案。该资料提供硫酸盐、黑碳、有机碳、沙尘及海盐等组分信息，使本研究能够从组分质量混合比出发估算近地面颗粒物浓度，而非依靠少量点位代表整个区域。与此同时，再分析值具有模式网格的空间代表尺度，不能直接视为单个地面监测站的测量结果[2—3]。

### 1.2 所用产品及其时空特征

本研究采用的具体产品为M2I3NVAER 5.12.4，对应文件标识inst3_3d_aer_Nv，属于三维、3小时、瞬时、模式层气溶胶质量混合比产品。选用该产品的直接原因，是其可在同一时空坐标下提供所需气溶胶组分和空气密度，并允许提取底部模式层，为后续近地面PM₁₀估算提供相互对应的输入。产品关键信息见表1，水平网格间距按“经度×纬度”列示[1]。

**表1  M2I3NVAER产品的主要信息**

| 项目 | 详细信息 |
| --- | --- |
| 产品简称／版本 | M2I3NVAER／5.12.4 |
| 文件产品标识 | inst3_3d_aer_Nv |
| CMR集合编号 | C1276812882-GES_DISC，用于对应实际请求的数据集合 |
| 主要物理量 | 气溶胶组分质量混合比及相关状态变量 |
| 产品时间覆盖 | 自1980年起；最新可用日期随数据发布更新 |
| 时间分辨率与性质 | 3小时瞬时值，每日8个时次 |
| 每日UTC时次 | 00、03、06、09、12、15、18、21时 |

使用该产品时，需区分网格、时次和模式层各自的物理含义。水平间距以经纬度表示，不等同于各纬度上相同的公里距离；每个3小时时次为瞬时场，不代表相邻3小时的平均状态；第72层为最接近地面的底部模式层，不是固定离地高度或固定气压面。产品时间覆盖自1980年起，但存在发布滞后，实际截止时间以NASA目录可用记录为准。

### 1.3 本研究选取的变量与范围

本研究从第72模式层选取14个变量，其中13个为所需气溶胶组分质量混合比，另1个为空气密度AIRDENS。变量集合与后续采用的组分估算方案对应，并非该产品的全部变量。质量混合比的单位为kg kg⁻¹，表示单位质量空气中的相应组分质量；只有与空气密度等信息结合并完成单位换算后，才能得到单位体积空气中的颗粒物质量浓度。表2列出实际请求的变量。其组分权重和具体换算公式在后续计算方法部分说明。

**表2  本研究获取的14个变量**

| 变量名称 | 物理含义 | 单位 |
| --- | --- | --- |
| AIRDENS | 空气密度 | kg m⁻³ |
| SO4 | 硫酸盐气溶胶质量混合比 | kg kg⁻¹ |
| BCPHOBIC、BCPHILIC | 疏水性、亲水性黑碳质量混合比 | kg kg⁻¹ |
| OCPHOBIC、OCPHILIC | 疏水性、亲水性有机碳质量混合比 | kg kg⁻¹ |
| DU001—DU004 | 第1至第4粒径档沙尘质量混合比 | kg kg⁻¹ |
| SS001—SS004 | 第1至第4粒径档海盐质量混合比 | kg kg⁻¹ |

空间范围分为国内四省区和国外七国。国内为宁夏、新疆、甘肃和内蒙古；国外为蒙古国、哈萨克斯坦、吉尔吉斯斯坦、塔吉克斯坦、阿富汗、巴基斯坦和印度。国内区域采用geoBoundaries的CHN ADM1省级边界，国外采用Natural Earth v5.1.2的1:50m国家级边界，下载和计算沿用对应区域多边形[4—5]。具体范围以实际边界版本为准，边界文件和校验信息随任务保留。

本阶段重点获取2015年至最新实际可用日期的数据，以衔接后续能够获得的地面观测资料；最终配对年段仍由观测有效覆盖决定。产品自1980年起的覆盖范围与本阶段重点下载范围需分别记录，不能将产品时间跨度等同于已经完成的研究数据范围。

### 1.4 数据下载方法

数据来源为NASA GES DISC，下载使用Earthdata Login账户认证，并按服务要求完成授权。本研究采用“先限定所需区域、变量、层次和时间，再获取实体文件”的子集方式，通过Python调用Harmony服务提交请求。这样可以在传输前减少无关空间和垂直层数据，降低全球三维资料带来的传输和存储负担，同时保留本研究所需的原始组分信息。

具体请求按区域和年份组织：历史完整年的范围为1月1日00时至12月31日21时（UTC），当前年份截至NASA目录最新实际可用时次；变量限定为表2所列14个变量，垂直条件为lev=72，空间条件为选定区域多边形。服务端完成处理后，程序获取逐日NetCDF结果链接并写入年度TXT，同时保存任务编号、请求条件、状态及有效期。年代目录仅用于管理年度清单，不改变日文件和原始时次的组织方式。

下载程序读取TXT清单，将实体日文件保存到相应地区和年份目录，先完成首次认证，再并发获取缺失文件。已有文件经过校验后复用，不能仅凭同名文件存在就认定完整。下载后检查日文件日期、日内时次、必要变量、lev坐标、单位和经纬度一致性：完整日应有8个时次，完整历史年应有365或366个日文件；任务部分成功或日期缺失时，不作为完整年度输入。

数据完整性检查与结果有效期分别管理。任务JSON和TXT用于追溯与下载，尚不代表实体数据已经到达本地；原始.nc4文件通过检查后才用于读取和计算。NASA临时结果链接过期会影响未完成下载的文件，但不影响已经保存在本地、通过校验的文件。中断或异常后优先恢复已有任务和缓存，避免无必要的重复获取。

### 1.5 数据读取、保存与后续使用

本研究实际使用Python的netCDF4库读取文件，通过维度、变量属性和坐标信息识别数据。读取时先检查time的单位与日历、lat和lon的坐标值、lev层次及变量单位，再提取同一位置和时次的输入。原始场通常按time、lev、lat、lon组织，子集可能只保留一个垂直层，须核实实际坐标值为72，不能仅按数组下标认定其为第72层。

本地处理保留原始水平网格，不在这一阶段重新投影或加密。区域覆盖以原生网格中心是否被目标多边形覆盖为准；年度结果仍以规则经纬度数组保存，区域外格点标记为缺失。由此，NetCDF文件在形式上具有矩形数组，并不表示研究范围改为整个外接矩形，后续使用应同时识别坐标与区域掩膜。

为避免混淆“下载的数据”和“计算的结果”，本研究区分原始区域子集、派生网格浓度和后续点位序列三个层次（表3）。下载所得日文件保留气溶胶组分及空气密度，不将其直接称为已经计算好的PM₁₀文件。年度PM₁₀由本地组分计算生成，保留时间、经纬度、模式层标识、单位、区域掩膜和公式等元数据；此处仅说明其使用关系，具体公式另述。

**表3  原始数据、派生结果与点位序列的区别**

| 数据层次 | 内容和组织 | 用途 |
| --- | --- | --- |
| 原始区域子集 | 逐日.nc4；所需组分质量混合比、空气密度和原始坐标 | 核查输入，保留复算依据 |
| 派生网格PM₁₀ | 按地区、年份保存NetCDF4；PM10变量按time、lat、lon组织 | 在完整区域网格上提取与分析 |
| 后续点位序列 | 按城市或站点组织多年序列；可导出CSV或Parquet | 时空配对、观测比较和统计分析 |

面向城市或站点的使用，则是在已有PM₁₀网格上按经核实的坐标提取时间序列，并保留目标坐标、匹配网格坐标和距离。原始时间及年度结果以UTC为基准；国内展示可增加北京时间UTC+8，跨国日统计需明确采用UTC日还是当地日。产品瞬时值与观测小时均值、日均值的统计含义不同，具体配对和聚合规则在后续匹配部分确定。

上述数据分层使后续分析具有可调整性：更换城市、站点或匹配方法时，从年度网格结果重新提取；调整计算方案时，从原始组分复算。完整本地文件的读取不依赖临时下载链接是否仍有效。总PM₁₀包括多类气溶胶组分，若研究进一步聚焦沙尘，应另行区分沙尘组分和总颗粒物浓度。
